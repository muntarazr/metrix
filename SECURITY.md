## Reporting a Vulnerability

Security is a fundamental priority for METRIX. If you discover a vulnerability, leak, or potential security flaw, please report it responsibly.

**Please do NOT disclose security vulnerabilities through public GitHub issues or discussions.**

Instead, please report the vulnerability privately by:
- Sending details via email to the maintainers at `security@metrix.app` (or opening a private GitHub Security Advisory).
- Including steps to reproduce, impacted components, and any proof-of-concept information.

### What to expect:
- An acknowledgment within 48 hours.
- A status update once the vulnerability has been triaged and reproduced.
- A coordinated fix and public disclosure timeline.
